Know what the evidence means

Source documented
A linked provider page or repository supports the named fact. It does not mean the tool was installed or tested.

Creator confirmed
A creator explicitly confirmed the named fact in an attributable source. A listing notification is not confirmation.

Community tested
A reviewed report records the exact host, platform, tool version, task, result and limitations.

Not established
The catalogue has no adequate evidence for that field. Unknown does not mean unsupported.

Discovery and sorting are AI-assisted; sources, uncertainty and editorial review govern the data. Stars measure GitHub interest, not quality. Separate Reactor inventory: 707 package records, outside the main catalogue.
