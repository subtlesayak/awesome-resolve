# Listing updates

Treat every "update listings" request as a review of **all sources used by this project so far**, not only the latest additions or the main Resolve subreddit. Follow [Every listings update](WEBSITE.md#every-listings-update) and [Contributing](CONTRIBUTING.md).

Build the source checklist from the maintained discovery/evidence ledgers, existing listings, credits and local research follow-up notes. Include every previously used source and retain newly discovered sources for future runs. Record inaccessible or incomplete checks explicitly; do not silently skip sources or claim exhaustive coverage.

Research reports, raw captures and private bookmark data stay local and must not be committed or uploaded. New listings require original-source verification and reviewed search tags. Maintenance-only changes do not warrant a catalogue release.
